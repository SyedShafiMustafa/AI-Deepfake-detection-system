# 🛡️ AI-Powered Deepfake Detection System

An AI-based application that detects whether an image is **Real** or **Deepfake** using the EfficientNet-B0 deep learning model.

## 🚀 Features

- Deepfake image detection
- EfficientNet-B0 pretrained model
- Fast AI inference
- PyTorch implementation
- Ready for Android integration

## 🧠 Tech Stack

- Python
- PyTorch
- OpenCV
- NumPy
- Pillow
- Streamlit
